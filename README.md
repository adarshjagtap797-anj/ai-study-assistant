# AI Study Assistant

## 📚 Project Overview
AI Study Assistant is a student-focused project designed to help students study, manage notes, solve doubts, and organize their study schedule.

## 🚀 Features
- 📚 Study Notes
- 🤖 AI Doubt Solver
- 📝 Previous Year Questions
- 📅 Study Timetable
- 📢 College Events

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- AI

## 🎯 Future Scope
- Personalized AI study plans
- Student login system
- Subject-wise notes
- AI-generated quizzes
- College-specific study resources
